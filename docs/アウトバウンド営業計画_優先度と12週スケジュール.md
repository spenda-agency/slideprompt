# アウトバウンド営業計画 — サービス優先度・チャネル別訴求・12週スケジュール

作成日: 2026-07-03
前提戦略: `docs/商材パッケージ戦略_年商1億ロードマップ.md`（診断→構築→伴走の3段パッケージ / 3軸KPI差別化 / 新規は月15万円以上）

保有チャネル:
- メルマガ: 300通 + 都度営業リスト作成
- 公式LINE: 200人（AIに興味あるユーザーが随時登録）
- YouTubeチャンネル
- 電話・メール営業（商談化の刈り取り）

## 1. サービス16本の優先度付け

判断基準: ①伴走（高LTV）に接続できるか ②実績・事例があるか ③保有チャネルの読者層に合うか。

### S: 主力（アウトバウンドの主打ち。全チャネルで露出）

| # | サービス | 役割 | 優先の理由 |
|---|---|---|---|
| S1 | **AIBIデータサポート / AI BIデータマーケティング作業代行版** | 旗艦「診断→構築→伴走」の受け皿 | 高LTVの本命。3軸KPI（自動化率・工数・サブスク費）の訴求がそのまま使える |
| S2 | **AIデータ相談し放題** | 低額サブスクの入口商品 | LINEの「AI興味層」にドンピシャ。心理障壁が最も低く、伴走へのアップセル母集団になる |
| S3 | **WEB広告プラス** | 広告不満層の乗り換え受け皿 | 実績最多（売上+156%、CV+665%等）。電話営業で最も話が早い「代理店への不満」を刺せる |

### A: 準主力（セグメント配信・スポット高単価。反応次第でSに昇格）

| # | サービス | 役割 |
|---|---|---|
| A1 | Looker Studioマルチビルダー / LookerStudio DX | 「レポート自動化・工数80%削減」訴求。制作会社・支援会社（OEM）にも刺さる |
| A2 | Tableau支援 / googletool | 100万円超の受注実績がある構築スポット。指名ニーズ向けセグメント配信 |
| A3 | リード獲得支援 / WEBマーケ戦略支援 | 単体では売らず「グロース診断」の提案内容に統合する |

### B: 実験枠（LINE・YouTube専用。商談単価が未証明のため主打ちしない）

| # | サービス | 扱い |
|---|---|---|
| B1 | AI社員リモートワーク（aiagentboard） | LINE/YouTubeのコンテンツネタ。反応が良ければ「AI導入支援」として伴走に接続 |
| B2 | Lbrain localllm | セキュリティ意識の高い企業（製造・医療・士業）向けの differentiator。YouTube解説ネタ |

### C: クロスセル専用（アウトバウンドでは打たない）

| # | サービス | 扱い |
|---|---|---|
| C1 | LP制作支援 / 動画静止画作成支援 | 広告運用の受注後クロスセル。単体訴求はしない |
| C2 | YouTube10T / 政治家YouTube | ニッチ。紹介・既存文脈のみ。アウトバウンド対象外 |

**要点: アウトバウンドで見せる「顔」はS1〜S3の3つだけに絞る。** 16本を並べると「何でも屋」に見えて単価が下がる（現状の構造問題の再演）。A群はメルマガのセグメント配信と商談内の提案で出す。

## 3. 12週スケジュール

構成: **W1-4 均等テスト → W5-8 絞り込み（勝ち筋に70%） → W9-12 集中刈り取り**

### フェーズ1: 均等テスト（W1-4）— 全オファー×全チャネルを1巡させる

| 週 | メルマガ（週1・火10時） | LINE（週1・水12時） | YouTube（週1本） | 電話・メール営業 |
|---|---|---|---|---|
| W1 | #1 S1訴求「広告費のムダ、金額でお見せします（無料簡易診断5枠）」 | #1 S2紹介「AI導入、何から始める？を月額で相談し放題」 | 「Looker Studioでレポート作成を自動化する実演（Before/After）」 | メルマガ#1の開封・クリック者に48h以内フォローコール |
| W2 | #2 A1訴求「レポート作成 月20時間→4時間にした方法（事例）」 | #2 AI活用事例小出し「広告レポートをAIに書かせたら」 | 「広告代理店の手数料20%、定額と比べるといくら損か」 | 新規リスト50件（EC/D2C）にS3コールドメール→コール |
| W3 | #3 S3訴求「代理店の乗り換え比較チェックリスト配布」 | #3 B1紹介「求人を出す前に"AI社員"という選択肢」 | 「GA4×AIで毎朝5分の経営ダッシュボードを作る」 | 新規リスト50件（多店舗・FC本部）にS1診断メール→コール |
| W4 | #4 S1再訴求・締切「無料簡易診断、今月枠残りわずか」 | #4 S2オファー「LINE登録者限定: 初月半額」 | 「サブスク費の棚卸し: ムダなSaaSの見つけ方」 | 新規リスト50件（マッチング/人材）+ W1-3反応者の再コール |

### 判定週（W4末）: 絞り込みルール

| 指標 | 継続ライン | 撤退ライン |
|---|---|---|
| メルマガ | 開封25% / クリック3% / 返信・申込 2件以上/月 | クリック1%未満のオファーは差し替え |
| LINE | 開封60% / タップ8% / S2申込またはアップセル面談 2件 | 反応ゼロのオファーはネタ変更 |
| YouTube | 視聴維持40% / 概要欄クリック→LINE登録 週5人 | 全滅なら「営業素材用」に割り切り本数半減 |
| 電話 | 接続率30% / 接続→商談化10%（=リスト50件で商談1-2件） | 業種セグメント単位で入れ替え |
| **総合** | **商談数で判定**: オファー別の商談化数 上位2つに絞る | — |

### フェーズ2: 絞り込み（W5-8）— 勝ちオファー2つに工数70%

- 勝ちオファーの配信頻度を週2に増、負けオファーは月1のストックコンテンツへ。
- 電話営業のリスト作成を勝ちオファーの反応業種に一本化（50件/週 → 80件/週）。
- W6: **ウェビナー#1開催**（勝ちオファーのテーマ。例:「広告費を増やさず売上を伸ばした3社の裏側」）。メルマガ・LINE・YouTubeの全チャネルで2週間前から集客。
- W8: ウェビナー参加者への個別相談オファー→診断受注。

### フェーズ3: 集中刈り取り（W9-12）

- 勝ちパターン（オファー×業種×チャネル）を型化: 件名・トーク・提案書をテンプレ固定。
- W10: ウェビナー#2（事例を1本追加して同テーマ再演）。
- W11-12: 診断納品→伴走契約のクロージング集中。次四半期リスト500件の仕込み。

### 12週の数値目標（逆算）

| 指標 | 目標 |
|---|---|
| 商談 | 24件（メール経由10 / 電話経由8 / LINE経由4 / ウェビナー経由2） |
| グロース診断 受注 | 8件（商談→診断 33%） |
| 伴走契約（月15万円〜） | 4社（診断→伴走 50%）＝ **MRR +60〜100万円** |
| リスト純増 | +600件（50件/週×12週） |
| LINE登録 | +100人（YouTube・メルマガ・ウェビナーから） |

## 4. オファー別の提案内容と訴求切り口

### S1 グロース診断 → AIBIデータサポート（伴走）

- **ターゲット**: 年商1〜50億のEC/D2C・多店舗FC・マッチング/人材。マーケ担当0〜2名で経営者が意思決定。
- **訴求切り口（フック）**:
  - 「広告費のムダ、**金額で**お見せします」（診断の成果物をそのまま件名に）
  - 「支援費用の何割かは、削減額でペイします」（3軸KPIの決め台詞）
  - 「代理店は成果しか見ない。システム会社は作って終わり。**両方見る会社**です」
- **提案内容（商談で出すもの)**: 簡易診断結果1枚（ムダ配信額・レポート工数・サブスク費の概算）→ 有料診断20万円（契約時全額充当）→ 90日ロードマップ→伴走。
- **メール件名例**: 「【○○業界】広告費の15%は"ムダ配信"です — 5分でわかる簡易診断」
- **電話トーク（30秒）**: 「広告やデータ分析を外部に出している会社様で、レポート作成の工数とツールのサブスク費まで含めて毎月数値で削減報告をする支援をしています。○○業界だと広告費の1〜2割のムダが見つかることが多く、まず無料の簡易診断だけでもと思いお電話しました」

### S2 AIデータ相談し放題（LINE主打ち）

- **ターゲット**: LINE登録済みのAI興味層。個人事業〜中小の担当者・経営者。
- **訴求切り口**:
  - 「AI導入、**何から始めるか**を決める相談相手を月額で」
  - 「ChatGPTを入れたけど業務が変わらない会社へ」
  - 「毎週のマーケ会議に"AIに詳しい外部の頭脳"を追加」
- **提案内容**: 月額サブスクの相談権 + 月次のAI活用レシピ配信。3ヶ月後にAI導入支援（構築）/伴走へアップセル。
- **LINE配信文例**: 「『AIで何ができるか社内で答えられる人がいない』— 先週のご相談で一番多かった悩みです。相談し放題プランなら、貴社の業務を聞いた上で"最初の3つ"をその場で決めます →（LP）」

### S3 WEB広告プラス（電話・メール主打ち）

- **ターゲット**: 既に広告代理店を使っている/インハウスで伸び悩む企業。
- **訴求切り口**:
  - 「手数料20%、やめませんか。**広告費に連動しない定額制**」
  - 「広告の"外"に原因があっても、代理店は直せません（GA4・サイト・ヒートマップまで一括）」
  - 「昨日までの結果を毎日共有。ブラックボックスにしません」
- **提案内容**: 現アカウントの無料診断（乗り換え比較表つき）→ 定額運用 + ツール群一括サポート。
- **メール件名例**: 「代理店の月次レポート、待たなくてよくなります（毎日自動更新）」

### A1 Looker Studio系（メルマガ・OEM営業）

- **ターゲット**: レポート業務が重い企業 + **制作会社・支援会社（OEM）**。
- **訴求切り口**: 「レポート作成 月20時間→4時間」「1社数十時間→2,3時間にした支援会社の事例」「貴社ブランドのままでOK（OEM）」
- **提案内容**: ダッシュボードのサンプルを見せる→初期構築+保守のセット見積→伴走接続。

### B1 AI社員 / B2 LocalLLM（LINE・YouTubeの実験枠）

- **訴求切り口**: 「求人を出す前に、AI社員」「社外に出せないデータこそ、社内AI（ローカルLLM）」
- **扱い**: コンテンツ反応の計測が目的。W4判定でクリックが多ければ「AI導入支援」の商談メニューに昇格。

## 5. 電話・メール営業の運用フロー

```
メルマガ/コールドメール配信
   → 開封・クリックを計測
   → 【48時間以内】反応者へ電話（つながらなければ翌日+3日後の計3回）
   → 接続: 30秒トーク → 「無料簡易診断」or「15分オンライン」を打診
   → 商談(30-45分): 簡易診断1枚を見せる → 有料診断20万円をクロージング
   → 不成立でもLINE登録・メルマガ許諾を取って育成に回す
```

- リスト作成は週50件を定常運用（業種はフェーズ判定に従う）。ソース: 業界ポータル、EC売上ランキング、求人媒体の出稿企業、FC加盟募集サイト、制作会社一覧。
- メール→電話の担当を分けない（文脈を持ったまま架電する方が商談化率が高い）。
- 全接触をスプレッドシートで管理: リスト/配信/開封/架電/商談/受注をファネルで週次集計（自社の3軸KPIダッシュボードのショーケースを兼ねる）。

## 6. YouTubeの位置づけ（直販ではなく信頼装置）

- 週1本・10分以内。テーマは「勝ちオファーのHow To公開」に限定（レポート自動化実演 / 広告アカウント診断の実演 / AI業務フロー構築）。
- 全動画の概要欄: LINE登録 → 診断オファーの2段導線。
- **商談前送付素材として使う**: アポ確定メールに関連動画を1本添付し、商談の説明時間を短縮・信頼を先回りで獲得。
- W4判定で登録者流入が弱ければ本数を月2に減らし、営業素材制作に割り切る。
